# dream-analysis
An agent skill used for analyzing dreams, distilled from the psychoanalytic corpus of Sigmund Freud (including "The Interpretation of Dreams", "Introductory Lectures on Psychoanalysis", "The Collected Works of Freud", and "Three Essays on the Theory of Sexuality").

Have fun.

# 梦的解析.skill
这个 Agent Skill 可不是普通的解梦工具——它吸收了弗洛伊德的毕生精髓：从《梦的解析》到《精神分析导论》，从《弗洛伊德全集》到《性学三论》，全都被它消化成了陪你聊梦的“潜意识嘴替”。
可以跟它聊那些奇怪的、反复出现的梦；它是最温柔的心理搭子，一边拆解你的梦，一边顺带剖析你白天不敢承认的小心思。

玩得开心～（顺便，别怪它太诚实。）
